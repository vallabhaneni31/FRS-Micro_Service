# Edith agents & commands

Quick reference for the agent loop and skills:

- `/edith-spec <feature>`: Draft a new specification folder (`requirements.md`, `design.md`, `tasks.md`).
- `/edith-spec-review <spec-dir>`: Run adversarial review on an existing spec.
- `/edith-spec-build <spec-dir>`: Implement an approved spec task-by-task, test-first.
- `/edith-status`: Check current spec progress and statuses.
